  • Si le centre bouge / tremble → FAIL (base instable).
  • Si les côtés sont conversables → FAIL (second rôle cassé).
  • Si large mais fragile en mono → FAIL (illusion).

  • Si le lead n’est pas indispensable → FAIL (plus de star).

[IF:FAIL] Symptômes signature → Action (format RUN)

A) Universels (7)

  1. Rôle du message flou
    CAUSE: hiérarchie non assumée, couches trop “lead-like”.
    ACTION: désigne une seule voix responsable du message, baisse la lisibilité des couches.
    RE-TEST: écoute en contexte + “Mute SUPPORTS”. [LISTEN:Role]
  2. Centre qui flotte
    CAUSE: ancrage centre insuffisant, trop d’animation sur le centre.
    ACTION: simplifie le centre jusqu’à une colonne stable.
    RE-TEST: passage dense + mono. [LISTEN:CenterSacred]
  3. Centre contaminé par la largeur
    CAUSE: largeur appliquée au centre, ou sides qui tirent l’attention.
    ACTION: retire l’élargissement du centre, laisse la largeur vivre sur les côtés.
    RE-TEST: side-only puis mono. [LISTEN:MonoStability]
  4. Centre agressif (fatigue)
    CAUSE: zone d’attention trop excitée au centre, densité mal répartie.
    ACTION: calme le centre jusqu’au confort avant embellissement.
    RE-TEST: bas volume + passage dense. [REF:R3-06]
  5. Côtés conversables
    CAUSE: supports trop lisibles / trop devant.
    ACTION: recule les côtés + retire leurs pics d’attention.
    RE-TEST: side-only + “Mute LEAD”.
  6. Largeur cheap / wobble / déséquilibre
    CAUSE: largeur forcée, cohérence latérale absente.
    ACTION: fixe une largeur officielle + rééquilibre L/R.
    RE-TEST: side-only + mono.
  7. Groupe pas “un seul instrument”
    CAUSE: décisions dispersées, bus utilisé pour réparer.
    ACTION: bus clairs (centre/côtés/final) + retire retouches partout.
    RE-TEST: bypass bus vocal final + A/B level-match. [REF:R3-05]
    STOP: si tu répares au bus, retourne construire les rôles. [REF:R3-03]

B) Spécifiques au PATH_COMMIT (5)

  1. Wide doubles → mono creuse → réduis largeur supports → re-test mono + dense.
  2. Stacks massifs → diction noyée → retire lisibilité couches → re-test bas volume + mute supports.
  3. Call & response → adlibs mini lead → audible oui / lisible non → re-test mute lead + side-only.
  4. Whispers/air → fizz/bruit → baisse zone d’attention → re-test dense + bas volume. [REF:R3-10]
  5. Formant/Chops → plusieurs personnages → centre reprend autorité → re-test mute supports + dense.

C) Spécifiques TARGET (3)

  1. DOUBLES: flam → stabiliser timing → re-test dense + side-only.
  2. HARMONIES: détourne focus → reculer + enlever lecture texte → re-test mute supports puis réintro.
  3. ADLIBS/CHOPS: vole l’oreille → tuer pics latéraux → re-test side-only + mute lead.

TECH PACK — P14 (General, PATH, TARGET)

Général

  • “Groupe vocal” = un instrument pilotable via bus (cohésion, glue, contrôle global).
  • Bus comp de groupe : cohésion, pas correction de prise.
  • Wet/Dry sur bus : doser un traitement comme un parallèle intégré.
  • Supports : plus sombres, plus larges, moins forts (soutien, pas concurrence).
  • Largeur : volume L/R, EQ L/R, timing L/R (prudence).
  • Wideners : surtout supports, rarement lead (centre stable).
  • Espace : lead = contrôlé ; supports = plus large et plus “arrière”.
  • De-essing : souvent plus strict sur backs/chœurs.
  • Parallèles : contrôle fort en parallèle plutôt qu’en direct sur le centre.
  • Routing conseillé : bus centre / bus côtés / bus vocal final / bus élargissement dédié.
  • Checks obligatoires si élargis : mono, side-only, voix creuse, stabilité centre/côtés. [REF:R3-14]

Preset PATH (un par chemin)

  • Lead solo centre : centre très stable ; supports rares ; risque “petit” si prod large.
  • Doubles tight mono : cohésion temporelle prioritaire ; risque flam ; utile articulation.
  • Wide doubles : micro-décorrélation ; risque mono creux/peigne ; garde un contrôle “mono-safe”.
  • Stacks massifs : masse chorale ; risque bouillie/fatigue ; centre prioritaire.
  • Whispers/air : texture très bas ; risque fizz/bruit ; discipline zone d’attention. [REF:R3-10]
  • Harmonies : rôle émotion ; risque détourner focus ; place derrière et enlève lecture texte.
  • Call & response : dialogue ; risque adlibs conversables ; “audible oui, lisible non”.
  • Formant personas : personnages ; risque “deux personnes” ; centre reste autorité.
  • Chops/voix-instrument : arrangement ; risque prend le lead ; fixe plafond de priorité.
  • Mid/Side design : centre ≠ côtés ; risque centre fragilisé ; protège centre, valide mono.

Preset TARGET

  • Lead : intelligible, centre stable, confort ; aucune largeur qui contamine.
  • Doubles : plus stables que naturelles, moins lisibles, plus larges ; de-ess renforcé.
  • Harmonies : plus arrière, plus matière que discours ; éviter qu’elles “racontent”.
  • Adlibs : ponctuation ; éviter détails qui volent l’oreille.
  • Chops : instrument ; décider lead ou décor ; si décor, limiter priorité.
  • Returns (vox FX) : sert la place, ne la remplace pas ; si tout bouge sans FX, décision mauvaise.

[BUSMAP:P14] Routing conseillé

Schéma

  • LEAD → Bus Centre → Bus Vocal Final → Vocal Master
  • DOUBLES/HARMONIES/ADLIBS/CHOPS → Bus Côtés (ou bus par rôle) → Bus Vocal Final → Vocal Master
  • Parallèle Comp / Parallèle Sat → Bus Vocal Final
  • Vox FX Returns → (Bus FX Vocal option) → Bus Vocal Final

ON/OFF attendu

  • Bus Centre ON: centre stable / OFF: reste logique (un peu moins fini)
  • Bus Côtés ON: soutien/largeur/texture / OFF: lead autosuffisante
  • Bus Vocal Final ON: cohésion légère / OFF: pas d’effondrement (sinon béquille) [REF:R3-03]
  • Bus d’élargissement ON: largeur supports / OFF: centre inchangé

MINI-MODULES STANDARD

  • Mono d’abord : si largeur casse en mono → réduis largeur supports avant tout.
  • Centre sacré : si côtés tirent l’attention → retire pics (attaques/sifflantes/mots) avant de monter le centre.
  • Bus = cohésion : si tu corriges au bus → reviens aux bus par rôle, puis revalide bus final OFF/ON. [REF:R3-03]
